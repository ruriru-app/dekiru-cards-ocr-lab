DEKIRU Cards OCR検証版 v0.1.1

このフォルダーは、写真からカードを作る前に、無料のブラウザーOCRでどこまで文字を読めるか確認するための検証ページです。
教材やカードへの登録は行いません。

【公開するとき】
index.html、ocr-lab.js、worker-entry-C9UNuyOJ.jsを、すべて同じ場所へ置いてください。
GitHubのアップロード画面でフォルダーが展開されても動作する構成です。

【使い方】
1. GitHub PagesのURLからindex.htmlを開きます。
2. 「写真を撮る」または「写真を選択」で画像を追加します。
3. 「文字認識を始める」を押します。
4. 画像上の番号付き枠と、下の認識結果を見比べます。
5. 必要なら「JSONを保存」で検証結果を残します。

【注意】
・初回は文字認識モデル等をインターネットから読み込むため時間がかかります。
・写真の文字認識は端末のブラウザー内で行い、外部のAIサービスには送りません。
・自信度はOCRエンジンの推定値であり、認識文字が正しいことを保証する点数ではありません。
・iPhoneで負荷が高い場合は、まず1〜2枚で試してください。
